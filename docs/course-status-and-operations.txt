四、Windows 第一次操作：依順序執行
=================================
操作位置請分清楚：
A. Windows PowerShell：安裝／查看 WSL。
B. Ubuntu 終端機：安裝 MySQL、執行 Python／Django。
C. Windows 瀏覽器：查看網站、登入後台與選擇素材。

步驟 1｜確認或安裝 WSL2
操作位置：以系統管理員身分開啟 Windows PowerShell。

先查看：
    wsl -l -v

如果尚未安裝 Ubuntu：
    wsl --install -d Ubuntu-24.04

依提示重新啟動，開啟 Ubuntu，建立 Linux 使用者與密碼。
再次查看 wsl -l -v，確認 Ubuntu 的 VERSION 為 2。
若發生錯誤，先保留錯誤文字回報，不要反覆重裝或刪除既有 WSL 資料。
成功判準：能開啟 Ubuntu 終端機。

步驟 2｜放置程式碼
操作位置：Ubuntu／Windows 檔案總管。

將最新 repo 放入 WSL 的 Linux 家目錄。
例如您的 repo 絕對路徑可以是 /home/您的Linux帳號/projects/test。
下列指令中的「您的Linux帳號」必須換成真實帳號；不是雲端代理工作目錄。

Windows 檔案總管可使用：
    \\wsl.localhost\Ubuntu-24.04\home\您的Linux帳號\projects

發行版名稱以 wsl -l -v 結果為準。若 projects 不存在，先在 Ubuntu 建立。
確認 repo 內有 manage.py、requirements.txt、README.md。
不要搬用 Windows 的 .venv，不要將私密設定／素材備份提交到 Git。

步驟 3｜安裝系統套件
操作位置：Ubuntu 終端機。

    sudo apt update
    sudo apt install python3 python3-venv python3-dev build-essential pkg-config default-libmysqlclient-dev mysql-server
    sudo service mysql start
    python3 --version

成功判準：Python 3.11 以上，MySQL 可以啟動。
本機階段不必設定 Nginx、公開網域或正式金流。

步驟 4｜建立 Python 環境
操作位置：Ubuntu 終端機。

    cd /home/您的Linux帳號/projects/test
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

首次尚無 .env 時才執行：
    cp .env.example .env
    chmod 600 .env

若已有 .env，先保留，不要覆蓋。使用文字編輯器（例如 nano .env）填入設定。
產生 SECRET_KEY：
    python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"

將產生值填入 .env，使用單引號包住；不要貼到對話或提交到 Git。

步驟 5｜建立 MySQL 資料庫
操作位置：Ubuntu 終端機，進入 MySQL：
    sudo mysql

以下只適用首次建立；密碼佔位文字要改成您自行設定的強密碼：
    CREATE DATABASE course_reader CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    CREATE USER 'course_reader'@'127.0.0.1' IDENTIFIED BY '<自行設定強密碼>';
    GRANT ALL PRIVILEGES ON course_reader.* TO 'course_reader'@'127.0.0.1';
    EXIT;

若顯示資料庫／帳號已存在，不要刪除資料庫，先確認既有設定。
若 sudo mysql 要求驗證而無法進入，請回報不含密碼的錯誤訊息。

步驟 6｜完成 .env
操作位置：Ubuntu 的 repo 目錄。

應設定：
    DB_NAME=course_reader
    DB_USER=course_reader
    DB_HOST=127.0.0.1
    DB_PORT=3306
    DEBUG=True
    ALLOWED_HOSTS=localhost,127.0.0.1
    ECPAY_ENVIRONMENT=test
    USE_X_ACCEL_REDIRECT=False

DB_PASSWORD 填入步驟 5 的相同密碼，並用單引號包住。
SECRET_KEY 填入步驟 4 產生的值，並用單引號包住。
目前 ECPAY_MERCHANT_ID、ECPAY_HASH_KEY、ECPAY_HASH_IV、SITE_URL 留空。
PRIVATE_MEDIA_ROOT 可留空，使用 repo 內的私有目錄。
不要填入虛構金鑰，不要改成 production。

Django 不會自行讀取 .env；在 Ubuntu 載入：
    set -a
    source .env
    set +a

步驟 7｜初始化及啟動
操作位置：相同 Ubuntu 終端機，需已啟用 .venv 及載入 .env。

    python manage.py check
    python manage.py migrate
    python manage.py createsuperuser
    python manage.py seed_demo
    python manage.py runserver

記住自己建立的管理員帳號；密碼不會顯示在終端機中是正常現象。
seed_demo 只建立原創佔位文字，不會產生您的實際音檔、書封或購買權限。
新建示範課程售價為 3680；既有課程仍須在後台確認。

操作位置：Windows 瀏覽器。
    首頁：http://localhost:8000/
    後台：http://localhost:8000/admin/

成功判準：首頁可開啟，superuser 可以登入後台。
Ubuntu 終端機需保持執行；Ctrl+C 可停止伺服器。
此網址只供本機開發，沒有公開上線。

五、後台建立實際課程與上傳素材
==============================
1. 用 superuser 登入後台，在「課程」新增實際課程。
2. 填課程名稱、公開銷售介紹、整套售價 3680。
   公開介紹不要放完整付費章節；不是把每章各訂 3680。
3. 在「章節」新增資料：選擇課程、填章節標籤、標題與排序。
   建議排序 10、20、30，方便日後插入；相同排序以章節 ID 決定先後。
4. 上傳 MP3；書封支援 JPG、JPEG、PNG、WebP。
   可以直接從 Windows 瀏覽器選擇本機檔案。
5. 填寫內容簡介並儲存，再開啟章節預覽。
   內容可使用 HTML，但只限受信任的 superuser；不要貼來源不明的程式碼。
6. 用 superuser 檢查音訊、書封、文字、上一章／下一章及「完成並繼續」。
7. 建立一般讀者帳號，另開無痕視窗測試；不要只用管理員驗收權限。

素材安全：
- MP3 上傳後放在 private_media，不要另放公開下載連結。
- media/covers 的書封可公開；請確認也有使用權。
- 原始素材另行備份，不要提交 Git。
- 若以前已有公開 media/audio，先依 README 的升級章節搬移，
  不要手動刪除唯一副本；該搬移指令核對後會刪除公開副本。

六、沒有綠界資料時，先完成本機驗收
================================
[ ] 首頁顯示正確課程與售價 NT$ 3,680。
[ ] 未登入者無法直接讀取章節。
[ ] 一般讀者未購買時，只能看銷售介紹，章節請求返回銷售頁。
[ ] 未設定綠界時，購買顯示付款服務尚未設定，不會開通課程。
[ ] superuser 可預覽全部章節（這是管理權限，不是付款成功）。
[ ] 後台為一般讀者新增「購買權限」：
    選對使用者／課程，勾「有效購買權限」與「僅限測試環境的權限」。
[ ] 該讀者可以閱讀／播放，並在「已購課程」看到課程。
[ ] 完成章節後進度更新，且不影響其他使用者／其他課程。
[ ] 管理員撤銷有效權限後，讀者後續章節及音檔請求被阻擋。
[ ] 手機或窄視窗可以展開／收合章節目錄。

手動開通只是在驗證權限，不是已付款證明。
撤銷不會收回已下載或已開始傳送的檔案；也不會自動退款。
測試完保留停用紀錄，不要把測試帳號權限當成正式買家。

八、常見問題與回報方式
======================
- 找不到 python／django：確認在 Ubuntu，且已 source .venv/bin/activate。
- SECRET_KEY 未設定：確認 .env 已填寫，且已用 set -a／source／set +a 載入。
- MySQL 連線失敗：確認服務啟動，DB_HOST／帳號／密碼與授權一致。
- 價格未顯示 3680：既有價格不會被 seed_demo 覆寫，請到後台編輯。
- 看不到播放器／書封：先確認章節有上傳對應素材並儲存。
- 一般帳號被導回銷售頁：確認該使用者在該課程的權限有效。
- 綠界尚未設定：現階段預期如此；localhost 不能接收外網付款通知。

回報請附：執行到哪一步、使用 PowerShell 還是 Ubuntu、
不含秘密的錯誤文字、預期與實際畫面。
不要提供整份 .env、密碼、SECRET_KEY、HashKey、HashIV、私鑰或登入 cookie。

[ ] 成功通知後才開通；偽造／錯誤金額／模擬通知不開通。

[ ] 未購買、其他課程買家、已撤銷者均不能取得音檔。
